03 · 核心功能

三个动作，覆盖一整页。

你不必为了读懂一页网页，先复制到翻译器，再粘回来。Verso把翻译放在你正在阅读的位置上。

01

全页翻译

一键把整页文字转换为你的母语。保留版式、链接、图片与排版；段落结构不变。

02

划词译注

选中任意词、句、段，浮窗立即给出译注、读音、例句。无需切换标签页。

machine learning
机器学习 n. /məˈʃiːn ˈlɜːrnɪŋ/ 让计算机从数据中学习规律的方法。
03

网页总结

把整篇文章压缩成三段要点与一句话摘要。点任何一句，跳回原文对应的位置。

核心论点：翻译不是字对字

三条论据：文化 / 节奏 / 留白

一句话：让另一种"她"重新呼吸

04 · 安装

三步，把Verso放进浏览器。

无需应用商店，从 GitHub Releases 下载安装包，加载后填入自己的 API Key 即可使用。

  1. 01

    下载安装包

    前往 GitHub Releases 下载最新版本的 zip 压缩包，解压到本地任意目录。

    URL https://github.com/yanlaoxier/ai-translator-extension/releases/latest
  2. 02

    加载扩展

    打开 chrome://extensions，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择解压后的目录。

    SHORTCUT Alt + T  ·  划词翻译
  3. 03

    配置 API 与语言

    首次打开插件弹窗，填写兼容 OpenAI 协议的 Base URL 与 API Key，并选择目标语言。

    CONFIG API Key 仅存本机 · chrome.storage.local

05 · 常见问题

关于Verso的细节。

Verso会上传我访问的网页吗？
不会。Verso默认在本地完成译注；只有在你主动开启「云端模型」时才会发起请求，浮窗内会显式标注，可随时关闭。
支持哪些语言？
目前支持 36 种主流语言互译，覆盖中文（简/繁）、英、日、韩、法、德、西、俄、阿拉伯、葡萄牙、意大利等。
在 PDF / 受密码保护的页面能用吗？
普通网页、RSS 阅读器、邮件网页版均可使用。本地 PDF 文件请使用桌面版Verso（macOS / Windows）。
团队 / 企业版有什么不同？
提供术语库、私有部署、SSO、权限管理与审计日志。请邮件联系 enterprise@verso.app。
